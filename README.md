# Singaraja Soccerfield - Management & POS System (PWA)

Sistem Kasir (POS), Booking Lapangan Mini Soccer, Laporan Harian, Pembuatan Invoice Resmi, dan Operasional **Singaraja Soccerfield** (Jl. Pulau Dewata 3, Pemaron, Buleleng, Bali).

## Fitur Utama
- **Kasir / POS Kafetaria:** Pembayaran Tunai (Cash) & QRIS dinamis, cetak struk thermal 58mm, dan notifikasi suara otomatis.
- **Booking Lapangan Mini Soccer:** Kalkulasi tarif otomatis (Weekday/Weekend & Pagi/Siang/Malam) serta deteksi jadwal bentrok.
- **Buat Invoice Resmi:** Cetak dokumen Invoice A4 multi-jadwal dan kirim langsung ke WhatsApp.
- **Bon Sementara & Pengeluaran:** Pencatatan piutang pemain serta pengeluaran operasional kasir dan maintenance lapangan.
- **Absensi & Kasbon Karyawan:** Pencatatan kehadiran harian dan pinjaman kasbon staf.
- **Sinkronisasi Cloud:** Terintegrasi dengan **Firebase Cloud Firestore** dan **Google Spreadsheet Webhook**.
- **Progressive Web App (PWA):** Siap diinstal sebagai aplikasi Android (`.apk` via PWABuilder atau langsung melalui Chrome Android).

## Cara Mengaktifkan GitHub Pages (Link HTTPS untuk PWABuilder)
1. Buka menu **Settings** di repositori GitHub ini.
2. Pilih menu **Pages** di bilah kiri.
3. Pada bagian **Build and deployment** > **Branch**, pilih **`main`** (atau `master`) dan folder **`/ (root)`**, lalu klik **Save**.
4. Tunggu sekitar 1 menit hingga link aktif muncul (`https://<username-anda>.github.io/<nama-repo>/`).
5. Masukkan link tersebut ke [PWABuilder.com](https://www.pwabuilder.com/) untuk mengunduh file `.apk` Android.
